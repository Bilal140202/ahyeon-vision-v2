# ahyeon-vision-v2 — Icon Dossier Vol.2 preview

Static build mirror of the `icon-dossier-v2` branch of
[Bilal140202/ahyeon-s-vision](https://github.com/Bilal140202/ahyeon-s-vision) (private).

- **Live preview:** https://bilal140202.github.io/ahyeon-vision-v2/
- **Identity:** "The Icon Dossier" v2.1 — bone paper, broadcast crimson, Syne/Martian Mono.
- Unofficial fan project — not affiliated with YG Entertainment.

## ✉ Fan Wire — contribute

This public repo is where fans file contributions, because the main dossier repo is private.
Use the **FILE A FAN WIRE** button on the site (or open an issue directly with the template)
to submit:

- **ADD A MOMENT** — a moment, fact, photo or video about Ahyeon that belongs in the dossier.
- **CHANGE A DETAIL** — something wrong or outdated on the page, with your source.
- **IMPROVE THE SITE** — design, copy, speed, accessibility, a section you wish existed.

Every wire is reviewed by @Bilal140202 before anything is folded into the dossier; approved
entries credit the submitter.

## 🛠 For maintainers

This repo is deploy-only: the `main` branch holds the production build output of the
`icon-dossier-v2` branch (built with `vite build --base=/ahyeon-vision-v2/`). Do not edit
`index.html` or `assets/` by hand — they are overwritten on each deploy. Site source, docs
(README / DESIGN / DATA / CHANGELOG / AGENTS) and history live in the private parent repo.
